# Killfeed

**Seu jogo. Seu status.**

Killfeed é um aplicativo mobile para jogadores de Counter-Strike 2 que querem acompanhar seu desempenho e competir com amigos. A proposta é transformar estatísticas reais de jogo em comparação, conquistas e rivalidade saudável.

## A experiência

- Entre com sua conta Steam.
- Confira seu perfil, avatar e estatísticas de desempenho.
- Acompanhe métricas como K/D, percentual de headshots e taxa de vitórias.

## Em desenvolvimento

O projeto está em fase inicial, com foco no login Steam e no perfil do jogador. As próximas etapas incluem CS Score, ranking mensal entre amigos e badges para destacar as conquistas de cada mês.

O aplicativo está sendo desenvolvido para Android e iOS com React Native e Expo, integrado a um backend Laravel.
